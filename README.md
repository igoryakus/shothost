# shothost

**ShotHost** — это легкая утилита, которая автоматически загружает ваши скриншоты на личный VPS через SSH/SFTP и мгновенно копирует ссылку для просмотра в буфер обмена. Сохраняйте полный контроль над своими медиафайлами, не полагаясь на сторонние фотохостинги.

### Возможности
* **Мгновенная загрузка:** Отправляйте скриншоты на сервер в тот же момент, когда файлы записываются на диск.
* **Автокопирование URL:** Готовая к отправке ссылка генерируется сразу и вы можете ей пользоваться, пока в фоне файл копируется на сервер.
* **Приватность на своем сервере:** Ваши изображения остаются в безопасности на вашем собственном VPS под вашим полным контролем.
* **Максимальная скорость:** Мгновенная прямая загрузка на VPS без задержек публичных хостингов.
* **Отсутствие рекламы:** Полное отсутствие баннеров, всплывающих окон, вотермарок и капч.
* **Вечное хранение:** Ваши файлы размещены навсегда и никогда не удалятся автоматически.

### Приложение для macOS

В папке [`macos-app`](macos-app) лежит приложение для строки меню. Все параметры задаются в окне настроек.

* **Сборка:** нужны Xcode или Command Line Tools (`xcode-select --install`), затем `./macos-app/build-app.sh`. Готовое приложение появится в `macos-app/build/ShotHost.app`, его нужно перенести в «Программы». Готовый ShotHost.dmg последней версии: https://github.com/igoryakus/shothost/releases/latest/download/ShotHost.dmg (собирается workflow «Release» по тегу vX.Y.Z).
* **Первый запуск:** приложение подписано без сертификата разработчика, поэтому в первый раз macOS его заблокирует. Откройте Системные настройки → Конфиденциальность и безопасность, в разделе «Безопасность» нажмите «Все равно открыть» и подтвердите паролем или Touch ID. Это нужно один раз.
* **Где приложение:** окна у него нет, только значок в строке меню. Если значок не виден (например, спрятан за вырезом экрана), запустите ShotHost из «Программ» ещё раз, и откроются настройки.
* **Настройка:** при первом запуске откроется окно настроек. Укажите папку со скриншотами, сервер, порт, пользователя, папку на сервере, SSH-ключ и адрес ShotHost, затем нажмите «Проверить соединение» и «Сохранить». «Папка ShotHost» это папка проекта на сервере, например `/var/www/html/shothost/`, файлы загружаются в её подпапку `files`. «Сайт» это домен или IP без пути (`https://example.com`), ссылка строится из сайта и названия папки: `https://example.com/shothost/...`. Владельцем `files` должен быть пользователь SSH, а группой `www-data` (`sudo chown -R $USER:www-data /var/www/html/shothost && sudo chmod 2775 /var/www/html/shothost/files`), иначе проверка соединения напишет, что папка недоступна для записи.
* **Работа:** новые файлы в папке переименовываются и загружаются так же, как скриптом, ссылка сразу копируется в буфер обмена, а после загрузки появляется окно со ссылкой и кнопкой «Показать» (в настройках его можно заменить уведомлением). В меню есть пауза, ручная загрузка файла, последние ссылки и автозапуск при входе в систему.
* **Если раньше пользовались скриптом `shothost.sh`**, выгрузите LaunchAgent и удалите его, чтобы файлы не загружались дважды: `launchctl unload ~/Library/LaunchAgents/com.user.shothost.plist && rm ~/Library/LaunchAgents/com.user.shothost.plist`.

### Приложение для Windows

В папке [`windows-app`](windows-app) лежит приложение для трея с теми же возможностями и настройками, что на Mac. Это один файл `ShotHost.exe` для Windows 10 и 11 на .NET Framework 4.8, который уже есть в системе, а загрузка идёт через встроенный клиент OpenSSH (`scp.exe`).

* **Сборка:** нужен .NET SDK 8, затем `windows-app\build.ps1`. Готовый файл появится в `windows-app\build\ShotHost.exe`. У сборок разработки серая иконка, обычная только у релиза (`SHOTHOST_RELEASE=1`, его задаёт workflow «Release»). Готовый ShotHost.exe последней версии: https://github.com/igoryakus/shothost/releases/latest/download/ShotHost.exe.
* **Первый запуск:** положите `ShotHost.exe` в постоянную папку (например `%LOCALAPPDATA%\Programs\ShotHost`) и запустите. Приложение не подписано, поэтому Windows покажет «Система Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае».
* **Где приложение:** значок в трее рядом с часами (в Windows 11 может быть спрятан под стрелкой `^`). Щелчок открывает настройки, правая кнопка открывает меню с паузой, ручной загрузкой и последними ссылками. Повторный запуск `ShotHost.exe` тоже открывает настройки, в том числе когда значок скрыт в настройках.
* **Настройки** хранятся в `%APPDATA%\ShotHost\settings.json`, автозапуск включается в настройках (раздел `Run` реестра текущего пользователя).
* **Если раньше пользовались скриптом `shothost.ps1`**, уберите его из автозагрузки, чтобы файлы не загружались дважды.
